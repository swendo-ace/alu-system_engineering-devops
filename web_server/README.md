# web_server

Bash scripts for configuring and deploying to a web server.

- `0-transfer_file`: transfers a file to a server's home directory using scp.
- `1-install_nginx_web_server`: installs nginx and serves a page containing Holberton School on port 80.
- `3-redirection`: configures nginx so /redirect_me returns a 301 redirect.
- `4-not_found_page_404`: configures nginx with a custom 404 page containing Ceci n'est pas une page.
